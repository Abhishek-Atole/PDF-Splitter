🎯 IF YOU DON'T HAVE WINDOWS ACCESS:

Step 1: Create GitHub account
   Visit: github.com (free)

Step 2: Upload project
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_NAME/PDF-Splitter.git
   git push -u origin main

Step 3: Enable Actions
   Go to: github.com/YOUR_NAME/PDF-Splitter/settings/actions
   Enable GitHub Actions

Step 4: Trigger build
   push code OR click "Run workflow" in Actions tab

Step 5: Download .exe
   Go to: Actions tab → Latest run → Artifacts
   Download PDFSplitter_Responsive.exe and PDFSplitter_Original.exe

✅ Done in ~3-5 minutes!
