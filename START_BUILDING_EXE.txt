METHOD 1: BUILD ON WINDOWS (⭐ RECOMMENDED - 2-3 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

STEP 1 - Transfer Files to Windows
─────────────────────────────────────
   Option A: Copy entire folder to USB/cloud and transfer
   Option B: Upload to GitHub then clone on Windows
   Option C: Email yourself the folder as zip

STEP 2 - Open PowerShell or Command Prompt on Windows
─────────────────────────────────────────────────────
   Windows Key + R
   Type: powershell
   Press Enter

STEP 3 - Navigate to folder
─────────────────────────────
   cd "Path\To\PDF Splitter"
   (Example: cd "C:\Users\YourName\Downloads\PDF Splitter")

STEP 4 - Create and activate virtual environment
───────────────────────────────────────────────
   python -m venv venv
   venv\Scripts\activate
   (You should see (venv) at the start of your command line)

STEP 5 - Install dependencies
────────────────────────────
   pip install PyPDF2 pdf2image Pillow customtkinter pyinstaller

STEP 6 - Build Responsive Version
─────────────────────────────────
   pyinstaller --onefile --windowed --name PDFSplitter_Responsive SPlitfile_responsive.py

STEP 7 - Build Original Version
──────────────────────────────
   pyinstaller --onefile --windowed --name PDFSplitter_Original SPlitfile_fixed.py

STEP 8 - Check your .exe files
──────────────────────────────
   dir dist\*.exe

✅ SUCCESS! Your files are in: dist\PDFSplitter_Responsive.exe and dist\PDFSplitter_Original.exe

⏱️  Total Time: 2-3 minutes

METHOD 2: USE GITHUB ACTIONS (⭐ AUTOMATED - ~5 MIN SETUP, THEN AUTOMATIC)
═══════════════════════════════════════════════════════════════════════════════

STEP 1 - Create GitHub Account
─────────────────────────────
   Visit: https://github.com
   Sign up (free)

STEP 2 - Create New Repository
───────────────────────────────
   Click "+" → "New repository"
   Name: PDF-Splitter
   Make it Public or Private
   Click "Create repository"

STEP 3 - Upload Your Project
────────────────────────────
   On your Linux/Mac/Windows machine, run:
   
   cd /path/to/PDF Splitter
   git init
   git add .
   git commit -m "Initial commit: PDF Splitter"
   git remote add origin https://github.com/YOUR_USERNAME/PDF-Splitter.git
   git branch -M main
   git push -u origin main

STEP 4 - Enable GitHub Actions
──────────────────────────────
   Go to: github.com/YOUR_USERNAME/PDF-Splitter
   Click "Actions" tab
   (GitHub Actions is already configured!)

STEP 5 - Trigger Build
─────────────────────
   Option A: Automatic - Push code:
      git push origin main
      
   Option B: Manual - Click button:
      Go to Actions tab
      Click "Build Windows .exe Files"
      Click "Run workflow" button

STEP 6 - Wait for Build
──────────────────────
   Watch the workflow run
   Should complete in 3-5 minutes
   Status: Green ✅ = Success

STEP 7 - Download Your .exe Files
─────────────────────────────────
   Click the latest successful run
   Scroll down to "Artifacts"
   Download:
      - PDFSplitter_Responsive
      - PDFSplitter_Original

✅ SUCCESS! You have your Windows .exe files!

⏱️  Total Time: ~5 minutes (one-time setup), then ~5 minutes per build after

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Python not found"
Solution: Ensure Python 3.12+ is installed
          Download from: python.org
          Check: python --version

Problem: "PyInstaller not found"
Solution: Run: pip install pyinstaller
          Then: pip show pyinstaller

Problem: "Build failed on Windows"
Solution: Check error message
          Ensure file paths have no special characters
          Try: pyinstaller --onefile SPlitfile_responsive.py -v
          (shows verbose output)

Problem: "GitHub Actions not running"
Solution: Check you pushed to correct branch (main)
          Check Actions tab is enabled
          Check .github/workflows/build-windows.yml exists

Problem: "Can't download from Artifacts"
Solution: Ensure build completed (green ✅)
          Look under "Artifacts" section
          Download the correct file
